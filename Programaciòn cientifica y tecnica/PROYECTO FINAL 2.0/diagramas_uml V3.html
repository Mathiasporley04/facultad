Diagrama de clases unificado

Documentación por clase

Qué hace cada clase y cómo se vincula con las demás. Agrupado por módulo.

A · Tipos del dominio (core/tipos.py)

TipoMercado

«enumeration» · core/tipos.py

Qué hace Enum de los tres tipos de mercado soportados: CRIPTO, ACCION_USA, DIVISA. Hereda de str + Enum para serializarse directo a texto.

Se vincula con Activo.tipo (cada subclase devuelve su valor), Mercado.tipo (clasifica el conjunto), y la UI lo usa para etiquetas y filtros.

Cotizacion

«dataclass(frozen=True)» · core/tipos.py

Qué hace Representa el resultado de pedirle el precio de ahora a una fuente: simbolo, precio, moneda y timestamp. Inmutable.

Se vincula con Producida por FuenteDatos.precio_actual() y por FuenteDatos.precio_actual_async(). CotizacionDTO.a_dominio() convierte un DTO validado en un Cotizacion.

PuntoPrecio

«dataclass(frozen=True)» · core/tipos.py

Qué hace Un punto en una serie temporal: fecha + precio. Inmutable.

Se vincula con Producido en lista por FuenteDatos.historico(). PuntoPrecioDTO.a_dominio() lo construye desde un dict validado. La UI (vistas/comparar.py, vistas/panorama.py) consume las listas para graficar.

B · Jerarquía de activos (core/activo.py + activos/)

Activo {abstract}

«ABC» · core/activo.py

Qué hace Contrato común de todo activo financiero: tiene simbolo, nombre, moneda_nativa y una fuente inyectada (composición). Provee obtener_historico() como método concreto que delega en la fuente. Las subclases solo deben implementar tipo y precio_actual_usd().

Se vincula con Tiene una FuenteDatos (composición). Sus 3 subclases (Cripto, AccionUSA, Divisa) implementan el polimorfismo. Mercado agrega activos en una lista.

Cripto

extends Activo · activos/cripto.py

Qué hace Criptomoneda. Su fuente (típicamente CoinGeckoAPI) ya devuelve precio en USD, así que precio_actual_usd() es pass-through. Agrega market_cap y ranking como atributos propios.

Se vincula con Hereda de Activo. Apunta a TipoMercado.CRIPTO. Suele usarse con CoinGeckoAPI como fuente.

AccionUSA

extends Activo · activos/accion_usa.py

Qué hace Acción estadounidense. Cotiza en USD nativamente, así que precio_actual_usd() es pass-through. Agrega sector (ej. "Technology") como metadato.

Se vincula con Hereda de Activo. Apunta a TipoMercado.ACCION_USA. Suele usarse con YahooFinanceAPI.

Divisa

extends Activo · activos/divisa.py

Qué hace Par cambiario. La "cotización" de la fuente es UYU por USD (o similar), entonces precio_actual_usd() invierte (1/cotizacion). Tiene par ("USD/UYU") y tipo_cotizacion (BROU, BCU, MEP...).

Se vincula con Hereda de Activo. Apunta a TipoMercado.DIVISA. Suele usarse con DolarApiUY.

C · Fuentes de datos externas (core/fuente.py + fuentes/)

FuenteDatos {abstract}

«ABC» · core/fuente.py

Qué hace Contrato uniforme para cualquier API externa. Tres métodos abstractos: precio_actual(simbolo), historico(simbolo, desde, hasta), listar_disponibles(). Un método concreto: precio_actual_async() que por default delega en asyncio.to_thread(self.precio_actual, ...). Las subclases con I/O nativo aiohttp overridean ese método.

Se vincula con Tres subclases concretas (CoinGecko, Yahoo, DolarApi). Es la parte fuente de la composición con Activo. Devuelve Cotizacion y listas de PuntoPrecio. Puede lanzar FuenteIndisponible.

CoinGeckoAPI

extends FuenteDatos · fuentes/coingecko.py

Qué hace Cliente HTTP para api.coingecko.com/api/v3. Mapea símbolos canónicos (BTC, ETH, SOL...) a IDs de CoinGecko. Implementa precio_actual e historico con requests (sync) y override de precio_actual_async con aiohttp. Usa @cache_ttl (60s precio actual, 3600s histórico).

Se vincula con Hereda de FuenteDatos. Devuelve Cotizacion en USD. Fuente típica de Cripto.

YahooFinanceAPI

extends FuenteDatos · fuentes/yahoo_finance.py

Qué hace Wrapper sobre yfinance (síncrono y bloqueante). Provee precio_actual (último cierre) e historico (rango diario). No overridea precio_actual_async; usa el default que despacha en thread vía asyncio.to_thread.

Se vincula con Hereda de FuenteDatos. Devuelve Cotizacion en USD. Fuente típica de AccionUSA. Cubre también índices como ^GSPC (S&P 500).

DolarApiUY

extends FuenteDatos · fuentes/dolar_api_uy.py

Qué hace Cliente HTTP para uy.dolarapi.com/v1/cotizaciones. Trae el snapshot de cotizaciones BROU y filtra por moneda (USD, EUR, BRL, ARS). Sin histórico público.

Se vincula con Hereda de FuenteDatos. Devuelve Cotizacion en UYU. Fuente típica de Divisa.

CotizacionDTO

«pydantic.BaseModel» · fuentes/esquemas.py

Qué hace Modelo Pydantic con validators: el simbolo y la moneda se canonican a uppercase y strip, la moneda debe tener len=3, el precio debe ser > 0. a_dominio() convierte al dataclass Cotizacion.

Se vincula con Produce un Cotizacion. Helper libre validar_cotizacion(dict) hace el round-trip dict crudo → DTO → dominio.

PuntoPrecioDTO

«pydantic.BaseModel» · fuentes/esquemas.py

Qué hace Modelo Pydantic para validar un punto histórico: fecha + precio con precio > 0. a_dominio() devuelve un PuntoPrecio.

Se vincula con Produce un PuntoPrecio. Helper validar_historico(list[dict]) hace el round-trip de una serie completa.
